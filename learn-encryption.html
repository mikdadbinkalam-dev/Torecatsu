How does encryption keep data safe?এনক্রিপশন কীভাবে ডেটা নিরাপদ রাখে?

Encryption scrambles data with a key so only someone with the right key can read it. Symmetric encryption uses one shared key. Public-key encryption uses a pair: a public key to lock, and a private key to unlock.

Public-key systems solve the problem of sharing a secret with someone you have never met. HTTPS uses them to set up a secure session, then switches to faster symmetric encryption.

Strong encryption is based on well-studied maths and open algorithms. Never invent your own; use trusted libraries.

এনক্রিপশন চাবি দিয়ে ডেটা এলোমেলো করে, ফলে সঠিক চাবি থাকলেই কেবল পড়া যায়। সিমেট্রিক এনক্রিপশনে একটি শেয়ার করা চাবি থাকে। পাবলিক-কি এনক্রিপশনে জোড়া চাবি: তালা দিতে পাবলিক কি, খুলতে প্রাইভেট কি।

অচেনা কারো সাথে গোপন কথা শেয়ারের সমস্যা পাবলিক-কি সমাধান করে। HTTPS এটি দিয়ে নিরাপদ সেশন শুরু করে, তারপর দ্রুত সিমেট্রিক এনক্রিপশনে যায়।

শক্তিশালী এনক্রিপশন ভালোভাবে পরীক্ষিত গণিত ও খোলা অ্যালগরিদমের উপর দাঁড়িয়ে। নিজে বানাবেন না, বিশ্বস্ত লাইব্রেরি ব্যবহার করুন।
