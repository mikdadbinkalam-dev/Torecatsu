NEXUS HYPER-MESHনেক্সাস হাইপার-মেশ

Community mesh networks

What it isএটি কী

A project about community mesh networks: neighbourhood devices that relay data for each other, so a network does not depend on one single provider.

কমিউনিটি মেশ নেটওয়ার্ক নিয়ে একটি প্রজেক্ট: আশেপাশের ডিভাইসগুলো একে অপরের ডেটা পৌঁছে দেয়, ফলে নেটওয়ার্ক একটি মাত্র প্রদানকারীর উপর নির্ভর করে না।

How we work on itআমরা কীভাবে কাজ করি

  • Learn how routing works in a mesh.
  • Test small low-cost radio and Wi-Fi setups.
  • Document what works so any community can copy it.
  • মেশে রাউটিং কীভাবে কাজ করে তা শেখা।
  • কম খরচের ছোট রেডিও ও Wi-Fi সেটআপ পরীক্ষা করা।
  • যা কাজ করে তা লিখে রাখা, যেন যে কোনো কমিউনিটি নকল করতে পারে।

Honest statusসৎ অবস্থা

This is a community research and learning project, not a finished commercial product. Current status: IDEA. We are learning and planning, and there is no released version, code or audit yet.

এটি কমিউনিটির গবেষণা ও শেখার প্রজেক্ট, সম্পূর্ণ বাণিজ্যিক পণ্য নয়। বর্তমান অবস্থা: IDEA। আমরা শিখছি ও পরিকল্পনা করছি; এখনো কোনো রিলিজ, কোড বা অডিট নেই।
