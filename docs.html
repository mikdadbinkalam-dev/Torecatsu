Getting Started

  1. Read the Manifesto to understand what TORECATSU stands for.
  2. Start learning on the Learn page. Pick a path from beginner to advanced.
  3. Ask TORE-AI (the chat button) a question. It answers from a built-in knowledge base.
  4. Create a free account with ACCESS PORTAL to get a member ID, or use the Join form to introduce yourself.
  5. Browse the project directory and tell us which idea you want to work on.

Technical Documentation

  • Site: static HTML, CSS and JavaScript hosted on Netlify. Source code: GitHub. No license has been added to the repository yet, so please do not assume it is open source.
  • Accounts and member list: Supabase Auth plus a members table with row-level security (everyone can read the list, users can only add their own row). Email addresses are not stored in that table.
  • Forms: Netlify Forms (join and contact).
  • TORE-AI: a local knowledge base in knowledge*.js, matched by keywords in your browser. It is not a large language model and can be wrong. An optional server function (netlify/functions/chat.js) can connect a real AI provider once an API key is set on the server.
  • 3D globe and effects: Three.js in the browser. Latency and node figures on the globe are simulated and labelled as such.
  • Languages: English and Bangla (toggle in the top bar).

Frequently Asked Questions

Is TORECATSU a company?

No. It is a student-led learning community.

What does "Break the system" mean?

Understanding how systems work and building better, open ones. It never means harming people or breaking the law.

Are the projects finished?

No. All six are ideas we are learning and planning. See each project page for its status.

Is it free?

Yes. Joining and creating an account are free.

Is TORE-AI a real AI model?

It is a built-in assistant that answers from a local knowledge base, so it is limited and can make mistakes.

Who can see my information?

Only your display name, member ID, level and join date appear in the public member list. See the Privacy Policy.

How do I report a problem?

Use the contact form with the topic "Report".

Contribution Guidelines

  • Write or improve a Learn article, translate to Bangla, suggest a project idea or report a mistake.
  • Say what you know and what you do not. Mark ideas as ideas and give sources for scientific claims.
  • Do not copy text, images or music you do not have the right to use.
  • Send your idea through the contact form with the topic "Contribute". Code contributions can be proposed on GitHub.

Code of Conduct

Be respectful, stay legal, be honest. Read the full Community Guidelines.
