How does a mesh network work?মেশ নেটওয়ার্ক কীভাবে কাজ করে?

In a mesh network every device can pass data along for its neighbours. There is no single central router that everything must go through.

If one node is switched off, the data finds another path, so the network heals itself. Routing protocols constantly share who is nearby and how good each link is.

Mesh networks are useful for communities with weak internet, in disasters, and for projects that want to avoid one point of control. The trade-off is that every extra hop can add delay.

মেশ নেটওয়ার্কে প্রতিটি ডিভাইস প্রতিবেশীর ডেটা এগিয়ে দিতে পারে। সবকিছু একটি কেন্দ্রীয় রাউটারের মধ্য দিয়ে যেতে হয় না।

একটি নোড বন্ধ হলে ডেটা অন্য পথ খুঁজে নেয়, তাই নেটওয়ার্ক নিজেই সেরে ওঠে। রাউটিং প্রোটোকল সবসময় জানায় কে কাছে আছে ও প্রতিটি লিংক কেমন।

দুর্বল ইন্টারনেটের কমিউনিটি, দুর্যোগ এবং এক জায়গায় নিয়ন্ত্রণ এড়াতে চাওয়া প্রজেক্টে এটি কাজে লাগে। অসুবিধা হলো প্রতিটি অতিরিক্ত হপে দেরি বাড়তে পারে।
